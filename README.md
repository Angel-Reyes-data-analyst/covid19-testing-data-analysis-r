# COVID-19 Testing Data Analysis with R

## Overview
This project demonstrates an end-to-end data analysis workflow using R and real-world COVID-19 testing data.
The analysis focuses on retrieving data via web scraping, cleaning and transforming raw data, and performing
basic exploratory analysis.

This project highlights practical data acquisition and preprocessing skills commonly required for junior
data analyst roles.

---

## Tools and Technologies
- R
- httr
- rvest

---

## Data Source
The data is obtained through web scraping from Wikipedia and contains COVID-19 testing statistics by country,
including testing counts, confirmed cases, and population-based ratios.

---

## Key Steps Performed
- HTTP requests to retrieve live web data
- HTML parsing and table extraction
- Data cleaning and preprocessing
- Data type conversion and validation
- Exporting cleaned data to CSV format

---

## Output
The cleaned dataset is exported as a CSV file (`covid.csv`) for further analysis or reuse.

---

## Notes
This project was developed as part of a professional data analytics training program and is intended to
demonstrate data collection, cleaning, and analytical reasoning using R.
